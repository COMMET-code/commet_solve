Hyperelasticity

Elasticity material specification

Parameters

  • id (int) required: ID of material domain.

  • orientation_vectors (list[string]) optional: List of field names to be used as orientation vectors (see Fields)

  • type (enum) required:

    • options: "ncm" | "traditional" (see Materials)

    • for this extension: "type"="traditional"

  • elasticity (json) required: description of the elastic material behaviour (see Hyperelasticity).

Examples

"materials": [
{
    "id": 0,
    "type": "traditional",
    "elasticity": {
        // specification for hyperelastic material behaviour
    }
},
{
    "id": 1,
    "type": "traditional",
    "orientation_vectors": ["my fibre field"],
    "elasticity": {
        // specification for hyperelastic material behaviour
    }
}
]
